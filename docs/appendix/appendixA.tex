\chapter{Mentor Pre-Session Checklist\\รายการเตรียมตัวก่อนการสนทนา}

\section*{48--24 ชั่วโมงก่อน Session}
\begin{itemize}
  \item[$\square$] ทบทวนเป้าหมายที่ Mentee เป็นเจ้าของ และบันทึกจากครั้งก่อน
  \item[$\square$] อ่าน Tech Portfolio หรือ artifact ล่าสุด โดยแยกข้อเท็จจริงออกจากข้อสันนิษฐาน
  \item[$\square$] เลือกคำถามสำคัญ 2--3 ข้อ ไม่เตรียมคำแนะนำมากเกินจำเป็น
  \item[$\square$] ตรวจผลประโยชน์ทับซ้อน ความลับ และข้อมูลที่ต้องได้รับความยินยอม
  \item[$\square$] ยืนยันเวลา สถานที่/ลิงก์ และผลลัพธ์ที่คาดหวัง
\end{itemize}

\section*{5 นาทีก่อน Session}
\begin{itemize}
  \item[$\square$] ปิดสิ่งรบกวนและจัดพื้นที่ที่รักษาความเป็นส่วนตัว
  \item[$\square$] สังเกตสภาวะของตน: กำลังรีบ ตัดสิน หรืออยากชี้นำหรือไม่
  \item[$\square$] เตือนตนว่า Mentee เป็นเจ้าของคำตอบและการตัดสินใจ
\end{itemize}

\section*{ระหว่าง Session}
\begin{itemize}
  \item[$\square$] ตกลง Goal ของเวลานี้
  \item[$\square$] ฟังและสรุปก่อนเสนอความเห็น
  \item[$\square$] ขออนุญาตก่อนท้าทายหรือเปลี่ยนหมวก
  \item[$\square$] ปิดด้วย action, owner, เวลา และวิธีติดตามที่ชัด
\end{itemize}

\section*{หลัง Session}
\begin{itemize}
  \item[$\square$] ส่งสรุปเฉพาะข้อมูลจำเป็นและตรวจขอบเขตการแบ่งปัน
  \item[$\square$] บันทึกสิ่งที่ตนเรียนรู้และอคติที่สังเกต
  \item[$\square$] ดำเนินการตามคำมั่นของ Mentor เช่น การเชื่อมบุคคลหรือส่งข้อมูล
\end{itemize}

\begin{mentornote}
Checklist มิได้แทนความใส่ใจ แต่ช่วยสงวนความใส่ใจไว้สำหรับสิ่งที่มนุษย์ต้องทำจริง: ฟัง ตีความ และอยู่กับ Mentee อย่างเต็มที่
\end{mentornote}
